## Read the scope with the name

Modules expose different representations and guarantees. A reference model or
bounded solver is useful on its documented input domain; the name alone does
not imply unbounded inputs, a particular approximation guarantee or a hardware
backend. Numerical routines state their precision and convergence assumptions.
The [quantum references](quantum-reference.md), for example, simulate amplitudes
classically and use exponential memory.

When exchanging a backend, also read [component contracts](contracts.md): its
allocation behavior, ordering, cursor lifetime and operation costs become part
of the consumer's behavior.
